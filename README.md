# گالری رسمی علی‌اکبر

یک گالری استاتیک فارسی، سریع و واکنش‌گرا. طراحی و توسعه: **مبین.آ**

## اجرای محلی

```bash
python3 -m http.server 8080
```
سپس `http://localhost:8080` را باز کنید.

## افزودن عکس تازه

1. عکس را داخل `assets/photos/` قرار دهید.
2. برای عنوان اختصاصی، نام فایل و عنوان را به `CURATED` در `tools/build-gallery.py` اضافه کنید (اختیاری).
3. فرمان زیر را اجرا کنید:

```bash
python3 tools/build-gallery.py
```

در GitHub Pages، Workflow موجود این کار را هنگام هر Push خودکار انجام می‌دهد؛ یعنی صرفاً آپلود عکس جدید در `assets/photos` نیز کافی است.

## انتشار روی GitHub Pages

در تنظیمات مخزن، وارد **Settings → Pages** شوید و Source را روی **GitHub Actions** بگذارید. سپس روی شاخه `main` پوش کنید.

> هیچ توکن یا رمز عبوری را داخل فایل‌ها Commit نکنید.
